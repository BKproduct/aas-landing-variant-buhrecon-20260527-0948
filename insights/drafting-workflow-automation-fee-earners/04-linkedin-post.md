# LinkedIn Post — Drafting workflow automation for fee-earners

Here is what drafting workflow automation should do in a law firm.

It should not give legal advice.
It should not decide strategy.
It should not send a document to a client.

It should do the repetitive first pass.

For example, when a client update is needed, the workflow can:

1. Read the case documents, emails and notes the firm has explicitly approved.
2. Pull out the names, dates, deadlines and key events.
3. Put those facts into the firm’s approved client-update template.
4. Mark anything missing, unclear or contradictory.
5. Hand the draft to the fee-earner for review.

Then the lawyer does the work only a lawyer should do:

- checks the facts
- decides what matters
- gives the advice
- changes the tone and wording
- approves the final document

That is the entire point.

The workflow does not replace professional judgement. It stops professional judgement being delayed by searching through the same file, copying the same information and rebuilding the same document structure.

The same logic works in accountancy, recruitment, advisory and claims teams: use automation to prepare the first draft; keep a human responsible for the final decision.

If someone claims “2× productivity”, ask one question: does that number include the human review and rework? If not, it is a headline, not a result.
